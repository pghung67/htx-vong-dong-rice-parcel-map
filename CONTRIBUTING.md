# Contributing / Đóng góp

Contributions are welcome: bug reports, documentation fixes, translations, and adaptations for other cooperatives.
Mọi đóng góp đều được hoan nghênh: báo lỗi, sửa tài liệu, dịch thuật và điều chỉnh cho các HTX khác.

1. Open an issue describing the change. / Mở issue mô tả thay đổi.
2. Fork the repository and create a branch. / Fork kho mã và tạo nhánh.
3. Submit a pull request. / Gửi pull request.

**Data privacy / Bảo mật dữ liệu:** never commit farmer names, phone numbers, or other personal data. Use anonymous parcel codes only.
Không đưa tên nông hộ, số điện thoại hay dữ liệu cá nhân vào kho mã. Chỉ dùng mã thửa ẩn danh.
